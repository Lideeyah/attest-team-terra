# Trees for Global Benefits demonstration assets

Run `npm run demo:assets` to download/cache the published source documents, verify the pinned PDD hash and prepare `demo/tgb-annual-report-2024.pdf` with `demo/sources.json`.

The registry reference and source documents concern a real project. Every household, payment, coverage figure and disbursement shown by the local demo is synthetic and must not be presented as ECOTRUST performance.

The consolidated backend specification requests A.13.1 / Table 5. The verified available May 2020 PDD uses J2.1 on page 47 and Table 12 for performance milestones. The demo keeps that actual citation and explicitly records `sourceAlignment: edition_pending`; it does not invent an A.13.1 quotation or allocate the unexplained remainder of the specification's 60/30/7 summary.

Payments are declared staged against verification. Reporting remains annual. The implementation does not infer household milestone eligibility or stage percentages from an unavailable document; enrolment evidence and explicit preflight exclusions remain recorded.

An authentic KML and a provenance-backed Markit issuance export are still external inputs. Test geometry is labelled synthetic.
